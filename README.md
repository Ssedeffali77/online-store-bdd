# Online Store BDD

## Description

Online Store BDD is a sample e-commerce system developed for demonstrating Behavior-Driven Development (BDD) using Cucumber and Java.

The system allows customers to browse products, add products to a shopping cart, and create orders. Administrators can manage products and monitor customer orders.

## Technologies Used

- Java 21
- Maven
- Cucumber
- JUnit 4
- IntelliJ IDEA

## Implemented Functionalities

- User Login
- Add Product to Cart
- Create Order

## Test Scenarios

The project contains **15 BDD test scenarios**:

- 5 Login scenarios
- 5 Cart scenarios
- 5 Order scenarios

The scenarios include both positive and negative test cases and demonstrate the expected behavior of the system under different conditions.
